# 🕊️ Hatoclip（ハトクリップ）

## Hatoclip とは

スマホと Windows PC のあいだで、コピーしたテキストを鳩（はと）が届けてくれるアプリです。
PC で動かしておけば、スマホは PC に表示される QR コードを読むだけ。アプリのインストールは不要です。

- やり取りできるのは **テキストだけ** です（画像やファイルは送れません）
- 通信は **同じ Wi-Fi の中だけ** で行います。インターネット上のサーバーとは一切通信しません

## 必要なもの

- Windows 10 または Windows 11 の PC
- カメラとブラウザがある iPhone（Android でも使えます）
- PC とスマホが **同じ Wi-Fi（同じルーター）** につながっていること
  - ゲスト用 Wi-Fi や、ルーターの「プライバシーセパレーター」（端末どうしの通信を遮断する機能）が有効な Wi-Fi では使えません

## インストール

1. `Hatoclip-<バージョン>-win-x64.zip` をダウンロードします（Surface Pro X などの ARM 版 Windows では `win-arm64` を選んでください）
2. zip を開き、中の `Hatoclip.exe` を好きなフォルダーに置きます（例：`C:\Users\<ユーザー名>\Hatoclip`）
   - zip に一緒に入っている `THIRD-PARTY-NOTICES.txt` は、Hatoclip に組み込まれているソフトウェア（.NET、QRCoder）のライセンス表示です。動かすのに必要なファイルではありません
3. `Hatoclip.exe` をダブルクリックします

### 「Windows によって PC が保護されました」と表示されたら

初回は青い画面（SmartScreen）が出ることがあります。

1. 「詳細情報」をクリック
2. 「実行」をクリック

個人が作ったアプリでコード署名をしていないため表示されるもので、ウイルスという意味ではありません。

### Windows ファイアウォールの確認が出たら

初回起動時に「Windows セキュリティの重要な警告」が出ます。

1. 「プライベート ネットワーク」にチェックを入れる
2. 「アクセスを許可する」をクリック

ここで許可しないと、スマホから PC に接続できません。
Hatoclip が自分でファイアウォールの設定を変えることはありません。
（`Hatoclip.exe` を別のフォルダーに移すと、もう一度この確認が出ることがあります）

### QR コードの画面

初回は「Hatoclip – 接続用QRコード」の画面が自動で開きます。
タスクバー右下の通知領域（タスクトレイ）に鳩のアイコンが出ていれば、起動しています。

## 使い方

### つなぐ（最初の 1 回）

1. PC の「接続用QRコード」の画面を開く（トレイの鳩アイコンをダブルクリックでも開きます）
2. iPhone の標準カメラで QR コードを読み取り、表示されたリンクをタップ
3. ページ上部に「<PC名> に接続中」と出れば OK です

一度つなげば、次からは同じページを開くだけで使えます（Safari のブックマークがおすすめ）。

### スマホ → PC に送る

1. 「スマホ → PC」の欄にテキストを貼り付ける
2. 「PCに送信」をタップ
3. 「PCに届けました」と出たら、PC 側で `Ctrl+V` で貼り付けられます

PC には「スマホから鳩が届きました」と通知が出ます（送ったテキストの先頭も表示されます。表示したくないときはトレイメニューの「通知に内容を表示」のチェックを外してください）。

### PC → スマホに取ってくる

1. PC でテキストをコピーしておく
2. スマホで「PCのクリップボードを取得」をタップ
3. 表示されたテキストの下の「コピー」をタップ

スマホが PC のクリップボードを取得すると、PC のトレイの鳩アイコンが数秒だけ青緑の矢印付きのアイコンに変わります（通知は出ません）。

### ホーム画面に追加する（任意）

Safari の共有ボタン →「ホーム画面に追加」で、アプリのように開けます。

ただし、ホーム画面に追加したアプリは Safari とデータが別なので、接続キーが引き継がれません。
「PCのQRコードを読み取ってください」と表示されたら、次のようにしてください。

1. Safari で（QR から開いた）Hatoclip のページを開く
2. 一番下の「ショートカットでもっと便利に（任意）」を開き、「接続キー」の「コピー」をタップ
3. ホーム画面のアプリに戻り、「接続キー」の欄に貼り付けて「接続」をタップ

## トレイメニュー

鳩のアイコンを右クリックすると、次のメニューが出ます。

| メニュー | 内容 |
|---|---|
| 接続用QRコードを表示 | QR コードと接続 URL、ネットワークの診断を表示します |
| Windows起動時に自動起動 | チェックを入れると、PC にサインインしたときに自動で起動します |
| スマホからの取得を許可 | チェックを外すと、スマホから PC のクリップボードを取得できなくなります（送信はできます） |
| 通知に内容を表示 | チェックを外すと、受信したときの通知に「スマホから鳩が届きました」だけを出し、テキストの中身は表示しません（既定はオン） |
| 履歴と同期に残さない | チェックを入れると、スマホから届いたテキストを Windows のクリップボード履歴（`Win+V`）やクラウドのクリップボード同期に残さないようにします。パスワードなどを送るときに便利です（既定はオフ。`Ctrl+V` での貼り付けは普段どおりできます） |
| 接続キーを再生成... | 接続キーを新しくします。今までつないだスマホは使えなくなるので、QR を読み直してください |
| 終了 | Hatoclip を終了します |

## iOS ショートカット（任意）

よく使う人は、iPhone の「ショートカット」アプリを使うと、ページを開かずにワンアクションで送受信できます。
iPhone の背面を 2 回たたく「背面タップ」に割り当てることもできます。
手順はページ下部の「ショートカットでもっと便利に（任意）」にあります。ショートカットの作り方は [docs/shortcut.md](docs/shortcut.md) を見てください。
ページのショートカット追加リンクは、iCloud リンクを `%LOCALAPPDATA%\Hatoclip\config.json` の `shortcutSendUrl` / `shortcutReceiveUrl` に設定すると押せるようになります（設定方法は [docs/shortcut.md](docs/shortcut.md)）。設定するまでは「（準備中）」と表示されます。

## トラブルシューティング

### Q. スマホから接続できない（「PCに接続できません」と出る）

順番に確認してください。

1. **同じ Wi-Fi か**：PC とスマホが同じ Wi-Fi につながっているか確認します。スマホがモバイル通信（4G/5G）になっていないかも確認してください
2. **ゲスト Wi-Fi ではないか**：ゲスト用 Wi-Fi や「プライバシーセパレーター」が有効な Wi-Fi では接続できません
3. **ファイアウォールで許可したか**：初回の確認で「キャンセル」した場合は、下の「ファイアウォールを許可し直す」を見てください
4. **ネットワークが「パブリック」になっていないか**：「プライベート」に変更します
   - Windows 11：設定 → ネットワークとインターネット → Wi-Fi（またはイーサネット）→ 接続中のネットワーク → 「プライベート ネットワーク」を選択
   - Windows 10：設定 → ネットワークとインターネット → Wi-Fi（またはイーサネット）→ 接続中のネットワーク名 → 「プライベート」を選択
5. **PC がスリープしていないか**：スリープ中は接続できません
6. **Hatoclip が起動しているか**：トレイに鳩のアイコンがあるか確認します

QR コードの画面の下には、ネットワークの診断が表示されます。

| 表示 | 意味 |
|---|---|
| ネットワーク: プライベート ✓ | 問題ありません |
| ⚠ このネットワークは「パブリック」になっています。… | 上の 4 の手順でプライベートに変更してください |
| ⚠ ファイアウォールでこのアプリが許可されていない可能性があります。 | 下の「ファイアウォールを許可し直す」を見てください |
| ⚠ LAN の IP アドレスが見つかりません。… | PC が Wi-Fi / 有線 LAN につながっていません |
| ネットワーク: 種類を確認できませんでした | 判定できなかっただけです。つながらないときは上の 1〜6 を確認してください |

**ファイアウォールを許可し直す**：「Windows セキュリティ」→「ファイアウォールとネットワーク保護」→「ファイアウォールによるアプリケーションの許可」→「設定の変更」で、一覧の「Hatoclip」の「プライベート」にチェックを入れて「OK」。一覧に無いときは「別のアプリの許可...」から `Hatoclip.exe` を追加します。

### Q. 「接続キーが一致しません」と出る

PC で接続キーが再生成されています。PC の QR コードをもう一度読み取ってください。

### Q. 「PCの設定で取得が許可されていません」と出る

トレイメニューの「スマホからの取得を許可」にチェックを入れてください。

### Q. PC の IP アドレスが変わった

QR コードの画面は自動で新しい内容に更新されます。スマホでもう一度 QR を読み取ってください。

### Q. `.local` の URL が開けない

ネットワークによっては `<PC名>.local` の名前が使えないことがあります。「URL（IP アドレス）」の方を使ってください（QR コードは IP アドレス版です）。

### Q. 送ったのに PC に貼り付けられていない

Hatoclip は PC のクリップボードに入れるだけで、自動では貼り付けません。貼り付けたい場所で `Ctrl+V` を押してください。
画像やファイルは送れません。

### Q. URL の最後の番号（ポート番号）が変わった

起動したときにほかのアプリが同じポート（既定は `52817`）を使っていると、Hatoclip はその回だけ空いている別のポートを使います。そのあいだはブックマークやショートカットが届かないので、QR コードを読み直してください。
このポートは設定には保存されません。いつものポートが空けば、次に Hatoclip を起動したときに元の番号に戻り、今までのブックマークやショートカットがそのまま使えます。

### Q. 「設定ファイルが壊れていたため、新しい設定を作成しました。」と出た

`config.json` が読めなかったので、新しい設定（新しい接続キー）を作りました。スマホで QR コードを読み直してください。元のファイルは同じフォルダーに `config.json.bak` などの名前で残っています。

### Q. 自動起動にしたのにトレイにアイコンが無い

タスクバー右下の「^」（隠れているインジケーター）の中に入っていることがあります。ドラッグしてタスクバーに出しておくと便利です。

## セキュリティについて

- 接続キーは `%LOCALAPPDATA%\Hatoclip\config.json` に保存されます。他の人に教えないでください
- スマホからの操作はすべて接続キーが必要です。キーを知らない端末からは使えません
- 間違ったキーで何度もアクセスされると、その端末からのアクセスを一時的に（10 分間）拒否します
- スマホが PC のクリップボードを取得するたびに、トレイの鳩アイコンが数秒だけ青緑の矢印付きのアイコンに変わります（スマホから届いたときはオレンジの封筒付き）。身に覚えがないのにアイコンが変わったときは、トレイメニューの「接続キーを再生成...」でキーを新しくしてください。取得自体をさせたくないときは「スマホからの取得を許可」のチェックを外します
- 受信の通知にはテキストの先頭が表示されます。人に画面を見られたくないときは「通知に内容を表示」のチェックを外してください
- スマホから届いたテキストは、通常の `Ctrl+C` と同じく Windows のクリップボード履歴（`Win+V`）やクラウド同期の対象になります。残したくないときは「履歴と同期に残さない」にチェックを入れてください
- インターネット上のサーバーとは一切通信しません（更新チェックや利用状況の送信もありません）
- ログ（`%LOCALAPPDATA%\Hatoclip\logs\`）にクリップボードの内容やキーは記録しません。ログは 14 日たつと自動で削除されます
- 通信は HTTPS ではなく HTTP です。同じ Wi-Fi の中では暗号化されずに流れるので、カフェなど信頼できない Wi-Fi では使わないでください

## アンインストール

1. トレイの鳩アイコンを右クリック →「終了」
2. 自動起動にしていた場合は、終了の前に「Windows起動時に自動起動」のチェックを外します
   - 外し忘れた場合は、レジストリの `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` から `Hatoclip` を削除します（チェックを外すとアプリがこれを削除します）
3. `Hatoclip.exe` を削除
4. `%LOCALAPPDATA%\Hatoclip` フォルダーを削除（設定とログが入っています。エクスプローラーのアドレス欄に `%LOCALAPPDATA%` と入力すると開けます）
5. （任意）ファイアウォールの許可を削除：「Windows セキュリティ」→「ファイアウォールとネットワーク保護」→「ファイアウォールによるアプリケーションの許可」→「設定の変更」→「Hatoclip」を選んで「削除」

## 開発者向け

- 技術：C# / .NET 10、WinForms（タスクトレイ）+ ASP.NET Core Kestrel（同一プロセス）、QR 生成に QRCoder
- ビルド：`dotnet build Hatoclip.sln`（本体だけなら `dotnet build src/Hatoclip/Hatoclip.csproj`）
- テスト：`dotnet test`（リポジトリのルートで実行。xUnit v3 を `global.json` で有効にした Microsoft.Testing.Platform で動かします。LAN や実際のクリップボードは使いません）
- 配布用 exe：`powershell -ExecutionPolicy Bypass -File tools\publish.ps1`
  - `publish\win-x64\Hatoclip.exe`、`publish\win-arm64\Hatoclip.exe`（self-contained の単一ファイル）と、それぞれの zip を作ります
  - zip には `Hatoclip.exe` と `THIRD-PARTY-NOTICES.txt`（同梱している .NET ランタイムと QRCoder のライセンス表示）が入ります
  - 1 つだけなら `dotnet publish src/Hatoclip/Hatoclip.csproj -p:PublishProfile=win-x64`

```
src/Hatoclip/          本体（トレイ、QR ウィンドウ、HTTP API）
src/Hatoclip/Web/      スマホ用ページ（exe に埋め込み）
src/Hatoclip/assets/   トレイ・exe のアイコン（tools/make-tray-icons.ps1 で生成）
tests/Hatoclip.Tests/  単体テスト・HTTP API のテスト（xUnit）
tools/                 publish.ps1、アイコン生成スクリプト
docs/design.md         設計メモ
docs/shortcut.md       iOS ショートカットの作り方
THIRD-PARTY-NOTICES.txt 同梱ソフトウェアのライセンス表示（zip に入れて配布）
global.json            テストランナーの指定
```
