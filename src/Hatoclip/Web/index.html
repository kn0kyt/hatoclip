接続を確認しています…

PCのQRコードを読み取ってください

PCのタスクトレイにある鳩のアイコンから「接続用QRコードを表示」を開き、iPhoneのカメラで読み取ってください。

ホーム画面に追加したアプリはSafariとデータが別なので、Safariで接続済みでも接続キーは引き継がれません。その場合は、SafariでQRから開いたページの「ショートカットでもっと便利に」で接続キーをコピーし、下の欄に貼り付けてください。

PC → スマホ

スマホ → PC

ショートカットでもっと便利に（任意）

iPhoneの「ショートカット」アプリを使うと、ページを開かずにワンアクションで送信・受信できます。背面タップ（iPhoneの背面を2回たたく）に割り当てることもできます。

送信用ショートカットを追加（準備中） 受信用ショートカットを追加（準備中）

ショートカットを追加するときに、次の2つを聞かれます。「コピー」して貼り付けてください。

背面タップに割り当てる

  1. 「設定」アプリを開く
  2. アクセシビリティ → タッチ → 背面タップ
  3. 「ダブルタップ」（または「トリプルタップ」）を選ぶ
  4. 一覧の下の方にある、追加したショートカットを選ぶ

このページはPCと同じWi-Fi内でのみ動作します。外部には何も送信しません。
