# iOS ショートカットの作り方（作者用）

送受信ページの「ショートカットでもっと便利に（任意）」から配布する、送信用・受信用の 2 つのショートカットの作り方です。
作ったショートカットは iCloud リンクで共有し、PC ごとの設定ファイル `%LOCALAPPDATA%\Hatoclip\config.json` に書き込みます（ビルドし直す必要はありません）。

## API の仕様（ショートカットが使うもの）

| 用途 | リクエスト | 成功時のレスポンス |
|---|---|---|
| 送信（スマホ → PC） | `POST <接続先URL>/api/clipboard`<br>ヘッダー `X-Hatoclip-Key: <接続キー>`<br>本文 JSON `{"text":"…"}`（`Content-Type: application/json`） | `200` `{"ok":true,"length":<文字数>}` |
| 受信（PC → スマホ） | `GET <接続先URL>/api/clipboard`<br>ヘッダー `X-Hatoclip-Key: <接続キー>` | `200` `{"ok":true,"text":"…","type":"text"}`<br>テキスト以外なら `"text":""`, `"type":"non-text"` |

- 接続先URL は `http://<PCのIP>:<ポート>`（例 `http://192.168.0.10:52817`）。末尾に `/` は付けない
- 本文は `text/plain`（UTF-8）でも受け付けますが、ショートカットでは JSON が扱いやすいです
- エラー：`400` 本文が空（`{"ok":false,"error":"empty"}`。PC のクリップボードは変更しません）／`401` キー不一致／`403` PC 側で取得が無効／`413` 1MB 超／`429` 認証失敗が続いて一時拒否（正しいキーなら拒否中でも通ります）／`503` PC のクリップボードが使用中
- 接続先URLと接続キーは、送受信ページの「ショートカットでもっと便利に」でコピーできます

## 共通：接続先URLと接続キーを「読み込み時の質問」にする

利用者ごとに URL とキーが違うので、どちらも「テキスト」アクションに入れて「読み込み時の質問」にします。

1. ショートカットの先頭に「テキスト」アクションを追加し、`http://192.168.0.10:52817` のような仮の値を入れる
2. 続けて「変数を設定」アクションを追加し、変数名を `接続先` にする
3. もう一つ「テキスト」アクションを追加し、`ここに接続キー` のような仮の値を入れる
4. 「変数を設定」で変数名を `キー` にする
5. 画面下の ⓘ（または名前の横の ⌄ →「詳細」）→「読み込み時の質問」→「質問を追加」で、1 と 3 のテキスト欄をそれぞれ選ぶ
6. 質問文を「接続先URL（Hatoclipのページからコピー）」「接続キー（Hatoclipのページからコピー）」にする

> **注意**：仮の値のまま共有してください。自分の PC のキーを入れたまま共有すると、受け取った人にキーの初期値として渡ることがあります。

## 送信用ショートカット（スマホ → PC）

名前の例：「PCに送る」（アイコンは鳩や紙飛行機など）

1. 上の「共通」の 4 アクション
2. 「クリップボードを取得」
3. 「URLの内容を取得」
   - URL：変数 `接続先` を挿入し、続けて `/api/clipboard` と入力
   - 「表示を増やす」をタップ
   - 方法：`POST`
   - ヘッダ：「新規ヘッダを追加」→ キー `X-Hatoclip-Key`、値に変数 `キー`
   - 本文を要求：`JSON`
   - 「新規フィールドを追加」→「テキスト」→ キー `text`、値に変数「クリップボード」
4. （任意）「通知を表示」：本文「PCに届けました」

## 受信用ショートカット（PC → スマホ）

名前の例：「PCから受け取る」

1. 上の「共通」の 4 アクション
2. 「URLの内容を取得」
   - URL：変数 `接続先` + `/api/clipboard`
   - 「表示を増やす」→ 方法：`GET`
   - ヘッダ：キー `X-Hatoclip-Key`、値に変数 `キー`
3. 「辞書の値を取得」：キー `text`、辞書は「URLの内容」
4. 「クリップボードにコピー」：「辞書の値」
5. （任意）「通知を表示」：本文「PCのクリップボードを受け取りました」

## 動作確認

1. PC で Hatoclip を起動し、iPhone を同じ Wi-Fi につなぐ
2. 各ショートカットを実行する。初回は「ローカルネットワーク上のデバイスの検出」や「〜への接続を許可」を聞かれるので許可する
3. 送信：iPhone でテキストをコピー → 送信用を実行 → PC で貼り付けて確認（日本語・絵文字・改行も）
4. 受信：PC でテキストをコピー → 受信用を実行 → iPhone で貼り付けて確認
5. キーをわざと 1 文字変えて実行し、`401` で失敗することも確認する（何度も繰り返すと `429` で一時拒否されるので注意）

## iCloud リンクで共有してページに載せる

1. ショートカットアプリの一覧でショートカットを長押し →「共有」→「iCloudリンクをコピー」
2. **タスクトレイのメニューから「終了」で Hatoclip を終了する**（Hatoclip は設定が変わるたびにこのファイルを書き直すので、起動中に手で編集すると上書きされて消えることがあります）
3. `%LOCALAPPDATA%\Hatoclip\config.json` をメモ帳などで開き、`shortcutSendUrl`（送信用）と `shortcutReceiveUrl`（受信用）に貼り付けて保存する（他の項目はそのまま）

   ```json
   {
     ...
     "shortcutSendUrl": "https://www.icloud.com/shortcuts/xxxxxxxx",
     "shortcutReceiveUrl": "https://www.icloud.com/shortcuts/yyyyyyyy"
   }
   ```

4. 編集後に Hatoclip を起動し直してください（config.json は起動時に読み込まれます）

空のまま（`""`）や `http://` / `https://` で始まる正しい URL でない間は、ページ上のリンクは「（準備中）」と表示されて押せません。
2 つのキーは初回起動時に空の値で config.json に書き込まれます。ページは接続確認のたびに PC からリンクを受け取るので、Hatoclip を起動し直したあとページの「再接続」を押すか開き直せば反映されます。

iCloud リンクは共有した時点の内容のコピーです。ショートカットを修正したら、もう一度リンクを作り直して config.json を更新してください。

## 背面タップに割り当てる

1. 「設定」→「アクセシビリティ」→「タッチ」→「背面タップ」
2. 「ダブルタップ」（または「トリプルタップ」）を選ぶ
3. 一覧の下の方の「ショートカット」から、送信用（または受信用）を選ぶ

これで、テキストをコピーして iPhone の背面を 2 回たたくだけで PC に届きます。
背面タップは iPhone 8 以降・iOS 14 以降で使えます。
